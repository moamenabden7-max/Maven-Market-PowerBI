# Maven Market Retail Analysis

Power BI analysis of retail sales and returns across products, customers, dates, and locations. The report uses a single interactive overview page.

## Business questions

- How do revenue, profit, transactions, and returns compare with the previous month?
- How does revenue trend by week?
- Which product brands contribute the most orders, revenue, and profit?
- How are transactions and sales distributed across countries and cities?

## Data

The working source files include sales data for 2017 and 2018, returns, products, stores, customers, regions, and a calendar. The report references a Power BI model with calendar, product, customer, and measure tables.

## Report overview

- KPI visuals for transactions, profit, and returns against prior-month values.
- Revenue gauge against a monthly target and a weekly revenue trend.
- Product-brand table with orders, revenue, profit margin, and return rate.
- Country treemap and customer-location map.
- Date and country slicers for exploring the results.

## How to open

Download `maven market.pbix` and open it with Power BI Desktop. The report contains an embedded data model; refreshing may require updated source settings.

## Tools

Power BI · Power Query · DAX · Excel/CSV
